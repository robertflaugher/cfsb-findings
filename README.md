# CFSB Field Findings

Field notes from systematic real-world testing of Claude for Small Business (CFSB), Anthropic's agentic workflow platform for SMBs launched May 13, 2026.

**Last updated:** 2026-06-19

---

## What's here

[FINDINGS.md](https://github.com/robertflaugher/cfsb-findings/blob/main/FINDINGS.md) documents confirmed platform behaviors, failure modes, UX friction points, and runtime data gathered during hands-on skill runs. Findings are organized by skill tested and platform behavior category, with a sequential ID (F-001, F-002, ...) unique to each finding across the whole file. Each finding carries a status tag: Confirmed, Unconfirmed, or Retracted.

Coverage is not tracked here, since it changes every session. See the section headers in FINDINGS.md for the current list of skills and connectors tested.

---

## Who this is for

**SMB owners and evaluators** — an honest picture of what works, what doesn't, and what you need to set up before your first skill run produces useful output.

**Developers building on CFSB** — structured field notes on edge cases and failure modes encountered during real-world testing.

---

## Updates

This repo is updated at the end of each documented testing session. Most recent findings appear at the top of each section in FINDINGS.md.
