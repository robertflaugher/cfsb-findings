# CFSB Field Findings

Field notes from systematic real-world testing of Claude for Small Business (CFSB), Anthropic's agentic workflow platform for SMBs launched May 13, 2026.

## What's here

[FINDINGS.md](./FINDINGS.md) documents confirmed platform behaviors, failure modes, UX friction points, and runtime data gathered during hands-on skill runs. Findings are organized by skill tested and platform behavior category. Each finding carries a status tag: Confirmed, Unconfirmed, or Retracted.

## Who this is for

**SMB owners and evaluators** — an honest picture of what works, what doesn't, and what you need to set up before your first skill run produces useful output.

**Developers building on CFSB** — structured field notes on edge cases and failure modes encountered during real-world testing.

## Current coverage

Skills tested: `/monday-brief`, `/call-list`
Connectors tested: QuickBooks Online, HubSpot, Gmail, Google Calendar, Google Drive

## Updates

This repo is updated at the end of each documented testing session. Most recent findings appear at the top of each section in FINDINGS.md.
